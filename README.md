# Customer Churn Classification

I compare logistic regression and decision trees on IBM telecom customer data.

## Run

Use a Python virtual environment. Install `pip install -r requirements.txt`, launch `jupyter notebook`, and open `customer-churn.ipynb`. Run cells from top to bottom. The notebook downloads the IBM Telco CSV.

## Scope and limitations

An exploratory notebook. Missing-value imputation fits the training partition only. No deployed service or newly verified score is claimed.
